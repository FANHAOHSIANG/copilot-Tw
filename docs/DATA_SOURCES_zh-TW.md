# 資料來源、控制分工與限制

[回首頁](../README.md) · [操作說明](INSTALL_zh-TW.md)

## 顯示、提醒、控制是三件事

| 資料 | 畫面／語音 | 傳給 C4 |
| --- | --- | --- |
| 所選高德的導航／轉彎 | 高德提供有效資料時可用 | 保留相容導航欄位；一般版能否提供取決於版本與廣播 |
| 高德智慧預調速 | 智慧調速頁顯示最近計算，非即時執行證明 | wide.39 固定使用所選高德的有效策略，台灣模式也保留 |
| 台灣道路速限 | 有效標誌／暫存標誌 | 選台灣來源且配對確認時可送；與高德有效預調速取較低值 |
| 台灣同路段測速 | 符合提醒配對時顯示／播報 | 控制使用既有 WideBridge 更嚴格的確認；新增提醒點不一定進入控制 |
| 區間公告位置 | 公告位置提醒／診斷 | 不把公告座標直接當成已驗證完整區間控制 |
| 神盾 | 投屏顯示神盾畫面 | 不擷取神盾內部測速資料 |
| Google 地圖 | 投屏 | 目前無 Google 圖資／速限／轉彎串接 |
| 60 秒暫存標誌 | 只延長顯示 | 不延長控制資料壽命 |

高德60、台灣道路100 → 送出道路上限60；高德100、台灣道路60 →60。測速相機的50與剩餘900公尺則仍保存在獨立測速欄位，由 C4 處理接近減速。本 App 沒有因此保證車端一定採用，也沒有取代 C4 原本控制。

## 固定測速覆蓋

以隨 wide.39 保留的 wide.37 資料及離線驗證為準：

| 項目 | 數量／狀態 |
| --- | --- |
| 警政署固定點快照 | 1,856 筆 |
| 可辨識方向 | 1,533 筆 |
| 提醒道路配對 | 487 點 |
| 未進入提醒配對 | 1,369 點 |
| 方向合成回放 | 539 組 |
| 已配對方向通過的點 | 457 點，僅代表合成目標選取通過 |
| 其他 | 3 點部分方向未觸發、19 點路徑不足、2 點同向未觸發、6 點反向異常待查 |

另有6點原資料雙向、只配對一向，與上表狀態重疊。沒有完成全台實地逐點驗證。一般平面道路不被一概排除，但須有可用道路與方向配對。語音門檻1公里不代表每個點都能提早1公里配對成功。

[逐點結果與方法](../variants/wide37/audit/README.md)。資料仍有漏報和可能誤配的限制，新增道路配對／經常出沒點需要另外驗證。本次沒有新增固定點或擴充控制資料。

## 開放資料與授權

- 固定點：2026-11-09 警政署「測速執法設置點」快照，[資料集](https://data.gov.tw/dataset/7320)。下載日不等於每個設備的更新日。
- 區間資料：保留新北24個方向診斷與後續16個公告座標；公告點缺少一致入口／出口定義，不能當完整執法模型。
- 機動／經常出沒點：沒有已整合的完整全台可定位資料庫；先前檢查的臺中386筆資料因缺可用經緯度，未加入 GPS 提醒。
- 政府資料依[政府資料開放授權條款](https://data.gov.tw/license)。道路資料與 HCOP 授權見[原始來源說明](../variants/hcop-tw/README_zh-TW.md)，OpenStreetMap 依其 ODbL 條款。

## 驗證界線

wide.39：26項離線合併測試、底欄結構測試、簽章與16KiB對齊、反編譯掛點／差異檢查通過。尚未完成該版 Android 實機、GPS 實路、C4 控制驗證。最新驗證紀錄位於 [variants/wide39/verification](../variants/wide39/verification)。
