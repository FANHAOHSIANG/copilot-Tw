# wide.46 與 CP Google 0.1.1 裝置驗收

適用：CoPilot tw `9.3.1-wide.46-enforcement-google`、CP Google 導航 `0.1.1-copilot`。這份文件是實際裝置的操作及紀錄方法；程式編譯、合成道路回放與桌面測試的通過結果不等於下表已完成。

## 1. 安裝與版本

1. 在同一台 Android 12 或更新裝置安裝本次兩個 APK。更新既有受控發行版時可直接覆蓋安裝；不要為了解決更新失敗先清除 App 資料。
2. 主程式版本應為 `9.3.1-wide.46-enforcement-google`，Google 配套為 `0.1.1-copilot`。若 Android 表示簽章衝突，先核對你目前安裝的是哪個發行來源。
3. 在 Google 配套的「設定／更換 Google 金鑰 → 複製套件名稱與 SHA-1」核對實際安裝版本。Google Cloud 申請、設定及金鑰限制依 [完整教學](GOOGLE_SDK_zh-TW.md) 操作。
4. 裝置需要可用的 Google Play services、Google 服務連線與精確定位。兩個 App 均須依系統提示完成需要的權限。

## 2. 停車時先確認中文語音

主程式右側面板按 **「更多 → 科技執法提醒與診斷」**：

1. 確認「科技執法提醒：開」與「科技執法語音：開」。
2. 按「試聽科技執法語音」。首次若顯示正在初始化，待狀態改變後再按一次。
3. 如顯示尚無離線中文語音，按「安裝／管理中文語音資料」，在系統文字轉語音設定安裝中文語音，再回來按試聽。新版會重新嘗試初始化。
4. 應實際聽到帶有「語音試聽」的句子。狀態顯示「語音引擎已接受」只能證明 TTS 接受，不代表裝置喇叭或藍牙已聽得見；確認媒體音量及實際音訊輸出裝置。
5. 試聽不會製造導航、限速、測速點或 C4 車控資料，也不代表附近有執法設備。

## 3. 開啟定位與觀察分類

按主面板「定位」啟動 GPS，不必輸入目的地。診斷應顯示清冊 **2,148 筆公告、1,152 筆有座標、996 筆待定位**，並隨定位更新附近候選。

| 畫面／狀態 | 驗收重點 |
| --- | --- |
| 前方科技執法 | 已通過同路、行向及適用條件判定；距離標示沿路 |
| 同路前方・方向待確認 | 不應被顯示成已確認取締本車行向；若符合接近條件播放，必須說「取締方向待確認」 |
| 條件待確認 | 時段或車種等未確認，只顯示，不主動播報 |
| 鄰近科技執法 | 不得把直線距離寫成沿路距離；不主動播報 |
| 執法公告參考 | 項目不明、純速度參考、尚未啟用或資料期限等狀態，不當成有效新語音提醒 |

靜止、GPS 精度不足、沒有確定道路、已通過公告或僅靠近鄰路時，沒有主動播報是預期結果。這次資料不是全台設備的即時狀態清單；無座標公告不能定位提醒。

## 4. 過期、關閉及原有提醒

| 操作 | 應觀察到的結果 |
| --- | --- |
| 按「停止」關閉 GPS | 科技執法候選撤回；舊結果不能回寫重現，正在播的相關語音撤銷 |
| 關閉科技執法提醒 | 畫面候選撤回；不再產生新科技執法語音 |
| 只關閉科技執法語音 | 畫面仍可顯示候選；正在播的科技執法語音停止 |
| 定位停止更新超過 3 秒 | 不應靠畫面重繪延長舊候選；舊科技執法語音撤銷 |
| 測速提醒實際開始播放 | 原測速提醒優先；科技執法聲音暫停，不在後面排長隊重播 |
| Google 即將轉彎及執法同時存在 | 轉彎主卡優先時，科技執法仍可在次提示條顯示 |
| 手機窄面板／橫向寬面板 | 車速、單位、限速圈與提醒不互相覆蓋；超長路名可省略 |

如果裝置曾暫停背景定位，重回前景後需等新的有效定位與道路判定；不能把舊畫面仍在視為接收正常。

## 5. Google 的三層驗收

依 [完整教學第 10 至 14 節](GOOGLE_SDK_zh-TW.md) 操作，分別記錄：

1. **配套 App：**初始化成功，能搜尋台灣目的地、計算並顯示路線。
2. **CoPilot 主程式：**來源選 CP Google 導航，持續讀到有效導航資料。配套的本機 HTTP 指示不等於 C4 回報。
3. **C4：**在實際接收端觀察對應更新，記錄接收端版本／commit。主機合約測試固定核對的使用者接收端為 `98331d2321fa063174a82cb7d17d2c5c8a35a004`；其他版本應另確認 next distance 語意。

檢查當前／下一步距離時使用同一時刻：目前轉彎 180 m、之後間隔 260 m，下一個轉彎總距離應是 440 m；不應重加目前距離變 620 m。這只是理解公式的例子，並非在 App 手動輸入的測試欄位。

停止導航、重新選目的地、切換來源及停止模擬後，舊導航應撤回。停止模擬會終止該次導航，重新選目的地才會開始真實導航；不能把模擬畫面用作真實 C4 接收驗收。

## 6. 取得可以重現問題的紀錄

停車時先到科技執法診斷頁按「開始測試紀錄（含 GPS 軌跡）」。行程結束停妥後按「停止並匯出測試紀錄 ZIP」，再按「複製科技執法診斷」。路程中不要由駕駛操作手機；需要觀察時由乘客記錄。

回報時附上：

- 手機型號、Android 版本、主程式與配套版本。
- 發生時間、道路／方向、看到的主卡與次提示文字。
- 是否聽到語音，是否說「方向待確認」，實際由手機或藍牙輸出。
- 診斷文字及測試 ZIP。ZIP 含定位軌跡，交給維護者分析即可，避免公開整段行程。
- Google 問題加上完整錯誤碼與 C4 版本；不要提供 API Key、付款資料或簽章私鑰。

`enforcement_alert` 日誌包含分類、距離、定位與過期單調時間及 `control_sent:false`。這些日誌能回溯提醒判定，不能單獨證明聲音確實到達喇叭，或 C4／車輛完成控制。
