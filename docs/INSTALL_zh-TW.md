# Copilot tw 安裝與使用（wide.40）

[回首頁](../README.md) · [下載 wide.39](https://github.com/FANHAOHSIANG/copilot-Tw/releases/tag/wide.40)

## 1. 安裝與更新

- Android 12 以上車機或手機。只需安裝一個 Copilot APK，不再分開安裝 Auto／Phone 版。
- 在版本頁下載 `Copilot-tw-9.3.1-wide.40-direction-alert.apk`，不是 GitHub 自動產生的 Source code ZIP。
- 停止投屏、關閉 App，在系統允許此次安裝來源後開啟 APK。同套件、同簽章可覆蓋更新並保留設定；若顯示簽章不相容，不要直接刪除原 App，先確認目前安裝來源並備份設定。
- 高德車機版、高德一般版、Google 地圖、神盾按需要另外安裝。APK 不含這些第三方 App。
- 首次開啟授予精確定位及系統實際要求的權限。測速位置取自執行 Copilot 的 Android 裝置，需確認車機 GPS 有有效定位。

## 2. 啟動投屏授權

1. 安裝 [Shizuku](https://github.com/RikkaApps/Shizuku/releases) 或 [Stellar](https://github.com/roro2239/Stellar/releases)，選一個管理。
2. 依管理工具引導開啟開發人員選項與無線偵錯，完成配對並啟動服務。沒有無線偵錯的車機，依工具的 USB ADB 說明操作。
3. 使用 Stellar 時確認其 Shizuku 相容層；回 Copilot 的導航「更多 → 啟動投屏／授權」，允許存取。
4. 「更多 → 投屏安裝與授權」可重看說明、選擇管理工具，或設定開 App 時開啟管理工具。

自動開啟管理工具不等於自動完成首次配對或授權。裝置重開機後若服務沒有啟動，須先恢復服務再開始投屏。

## 3. 選擇導航與右側畫面

- 導航「更多」：切換高德車機版／一般版／Google 地圖。切高德會同步切換接受的高德資料來源，撤銷舊資料，等待新來源提供有效欄位。
- Google 地圖目前只有畫面投屏；不解析 Google 的速限、測速、路線給 C4，切換後高德資料停用。
- 右側切換「台灣測速」或「神盾投屏」。神盾只是顯示另一個 App；台灣 GPS 提醒與高德資料各依自身有效性處理。
- 長按分隔把手可調整比例；橫向、直向分別保存。右側「更多」中的設定頁，關閉鈕固定在底部中央。
- 一般高德搜尋時若鍵盤被擠壓，先確認使用新版並完成投屏授權；記錄 Android 版本、螢幕比例及鍵盤 App，提供發生時畫面以便排查。

## 4. 台灣測速怎麼看

- 主區顯示即時時速；有有效速限才顯示標誌。有前方提醒時顯示測速距離，接近時放大。
- 底欄提供 GPS／道路與提醒來源。標誌暫存最多 60 秒，暫存不是新的道路速限證據。
- 符合配對條件後，語音門檻為 1 公里，依點位層級播報「前方平面道路測速」／「前方高架道路測速」，未分類播報「前方測速照相」；500 公尺內出現全畫面邊緣紅光。
- 示範用來看畫面／聲音，不代表目前 GPS 有測速，也不代表示範速度已傳給 C4。
- 停車、GPS 品質不佳、路段不明或點位未配對時可能不提醒。不要用「附近有點」推論「一定是本車前方點」。
- 區間公告位置提醒不等於已建立完整入口／出口或平均速率執法模型；不能將所有公告點視為可控車的區間資料。

## 5. 連 C4 與選資料來源

1. Android 裝置與 C4 需能互相連線。在 App 連線設定填實際 C4 位址，確認車況更新；不要照抄別人的 IP。
2. 車況連上、導航送出、車端採用是不同步驟。查看診斷中的有效資料時間、握手／斷線、`speed_wire` 與車端接收紀錄。
3. 選用「HCOP 台灣道路速限＋測速（測試）」時，台灣提供通過確認的道路速限與測速點。畫面選神盾並不會自動把 C4 改成神盾資料。
4. wide.39 的預調速固定由所選高德提供；與台灣有效道路速限同時存在時取較低值。台灣相機速限和距離另以測速欄位保留。
5. 高德策略失效／過期就撤銷，不因畫面速限保留 1 分鐘而繼續控車。重新開 App 或切換來源後，請以診斷顯示的實際來源為準。

| 外框 | 意義 |
| --- | --- |
| 水藍 | 僅橫向接管 |
| 綠色 | 橫向、縱向均接管 |
| 無外框 | 橫向未接管或沒有相應狀態；不是判斷連線成功的唯一依據 |

最終採用的速度與加減速由 C4 分支、參數、資料新鮮度及其他控制限制決定。此版尚無實車減速驗證。

## 6. Tesla 瀏覽器僅投神盾

先完成 Android 端神盾安裝與投屏授權，在導航「更多」開啟「Amap2Tesla 僅投神盾」，依原投屏流程啟動，使用車機瀏覽器開啟 App 顯示的網址。更換模式前先停止投屏。網路必須互通；此項是 Android 功能，不能直接套用到 iPhone。

## 7. 排錯與檔案驗證

| 現象 | 先檢查 |
| --- | --- |
| 沒有測速提醒 | 精確定位、GPS 年齡／精度、路段與方向、是否屬已配對點；詳見資料範圍 |
| 畫面有點但 C4 沒採用 | 控制來源、同路段確認、speed_wire、車端接收紀錄；預覽不是控制輸入 |
| 投屏黑畫面 | 目標 App 是否安裝、Shizuku／Stellar 服務與授權、停止後重新開始投屏 |
| 沒語音 | 媒體音量／靜音、音訊輸出裝置、是否真的觸發提醒；示範僅測聲音與畫面 |
| 更新失敗 | 下載是否完整、Android 版本、現有套件簽章及版本碼 |

macOS：`shasum -a 256 檔名.apk`；Linux：`sha256sum 檔名.apk`。與同一 Release 的 SHA256SUMS 比對。
