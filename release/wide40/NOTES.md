# Copilot tw wide.40（測試版）

修正測速提醒容易卡在方向／道路確認的情況：以連續GPS軌跡補足缺少的方向／速度；提醒端允許高架和平面模糊時提示前方同向候選，按測速點道路圖資標示層級。

- 平面語音：前方平面道路測速。
- 高架語音：前方高架道路測速。
- 未分類保留原A聲音「前方測速照相」。新增兩段台灣中文女聲，不保證與原A音色相同。
- 語音門檻1公里，紅光500公尺，保留wide.39高德預調速綁定及固定關閉按鈕。
- 只放寬App提醒，C4控制仍使用原始定位與嚴格道路確認；可能提醒另一層道路，不猜車輛所在樓層。

30項離線測試及APK簽章／對齊通過；未完成Android實機／實路GPS／C4實車驗證。仍沿用487個已配對提醒點，非全台1856點皆可觸發。圖資層級可能有缺漏或過時。
