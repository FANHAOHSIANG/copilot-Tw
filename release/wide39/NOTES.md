# Copilot tw wide.39（測試版）

Android 12 以上；一個 APK 切換高德車機／一般版，右側使用台灣測速或神盾投屏。

- 高德預調速固定綁定所選高德，切台灣來源仍保留有效策略；與台灣有效道路速限取較低值送出。
- 台灣測速點速限／距離仍保留；資料逾時撤銷。
- 更多設定頁的關閉按鈕固定在底部中央。
- 整理功能、安裝、投屏與 C4 來源說明。

**下載 `.apk` 安裝；`Copilot-tw-wide.39-source.zip` 是原始碼與修改材料，不是安裝檔。** 同簽章可覆蓋更新。SHA256SUMS 可驗證兩個檔案。

26項離線速度測試、底欄結構、APK簽章／對齊檢查通過。尚未完成 wide.39 Android 實機及 C4 實車驗證。固定點雖有1856筆，目前487點具提醒道路配對，並非全台全部點均能提醒；覆蓋與異常請看首頁。
