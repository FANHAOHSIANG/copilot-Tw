# Carrot Bridge wide.63 更新與驗證說明

版本 9.3.1-wide.63-ui（26110775），以 wide.60 APK 為可重建基底。原簽章與 wide.62 相同，可依 Android 更新流程覆蓋。最低 Android 12。

- 取得精確位置權限後自動啟動 OSM 定位。臺灣離線圖資包含 5,927 個 OSM 圖磚。設定可分別控制速限牌顯示及傳送道路速限至 C4，傳送預設關閉。
- OSM 速限牌為 66 dp，長按拖曳，輕點可重設位置，Google 導航 NOO、高德一般版及車機版分別記憶位置。
- 地圖與神盾拖曳分隔線時等比縮放現有投屏。來源與格子比例不同時可能留邊。
- 「神盾取樣診斷與尺寸保護」預設關閉。開啟後以 757 × 384 px 為基準限制縮小，並在記錄中產生 shield_frame 事件。神盾即時數字辨識和 C4 傳送尚未接入。
- 本版道路速限取自 OSM。官方道路速限表尚未接入，Navi v2 引導狀態跳動也未在本版調整。

## 驗證範圍

已編譯與組譯主 DEX、Google DEX，驗證套件版本、簽章、對齊及離線圖磚。既有 wide.62 的車端紀錄曾確認高德路線和引導送達。wide.63 尚無車機安裝、三地圖切換、神盾取樣或 C4 OSM 速限實機驗收紀錄。

GitHub App 主分支基底為 28349dc。C4 測試分支已查得 1fef6217，本次 App 發布未更新車端分支。
