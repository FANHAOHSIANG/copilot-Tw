# Navipilot 9.3.1-wide.15-phone-bridge

這版依使用者要求，以 wide.11 車機版為基底，將左側投屏及高德開啟目標換成一般手機版 `com.autonavi.minimap`，保留車機版原本的廣播解析、Navi v2 與 UDP 流程。右上維持神盾投屏、右下控制鈕及可拖曳邊界。這是一般版串接測試包，並非台灣測速面板版。

## 實際做到的範圍

- 原 `Z3`、`IG`、`MG`、`Od` 與 wide.11-auto 逐檔相同。廣播接收器 `h4` 只加觀察記錄；原來支援的標準廣播及一般版 action 處理不變。
- 沿用既有 Navi v2 WebSocket（通常為 7714）的握手、欄位格式、資料時間、排程和撤銷處理。沒有第二套導航發送器，沒有把一般通知文字轉成控制資料。
- 沿用原 UDP 定位及按鍵命令。與舊 probe 不同，這版沒有 `Od.k` 的攔截／返回 false 修改；不代表舊 probe 曾停用所有 Navi v2 流程。
- 若一般版輸出原解析器支援的結構化導航／測速廣播，資料可沿原設定及有效性檢查進入既有傳送流程。缺少來源資料時，不會從狀態心跳捏造轉彎、速限、測速距離或路線。
- 修正通知取樣：開始／重新取樣後立即取得現有通知；也可手動讀取。分開顯示更新與快照筆數，來源限定一般版高德。快照可嘗試讀取自訂通知版面的文字；不保證所有 RemoteViews 都可讀。
- 廣播改成每類計數、每類最新內容；顯示有界限的欄位名稱、型別與值，包含以前漏記的 ICON、NEW_ICON、LIMITED_SPEED 等。通知、廣播及排入紀錄各自保存，避免心跳洗掉所有樣本。
- 診斷分開呈現原 Navi v2 佇列結果與 Carrot 回傳的導航、測速欄位。佇列接受不等於接收或減速執行；Carrot 回傳也不能直接證明來源一定是一般版高德。
- 保留 wide.10 雙投屏互相釋放修正，以及 wide.11 車況連線診斷。

## 安裝與驗證

1. 停止投屏、關閉 CP搭子後，覆蓋安裝 `Navipilot-9.3.1-wide.15-phone-bridge.apk`。套件及簽章沿用前版，不用先解除安裝。
2. 在系統 App 資訊中強制停止高德車機版，避免它的背景廣播混入。診斷頁提供車機版 App 資訊入口。單憑廣播 action 無法驗證發送者；已安裝也不代表正在執行。
3. 開一般版高德導航，保留既有 C4 連線與導航傳送設定。
4. 右上「版面」→「一般版高德串接診斷」→「開始／重新取樣」。已授予通知存取時，可直接取得通知欄內已有的高德通知。
5. 約 30–60 秒後按「分享診斷檔」。檔案包含一般版高德通知、廣播、導航位置欄位、原通道排入紀錄及 Carrot 回傳，分享前可檢查內容。

結果要核對：一般版通知是否取得、是否有實際轉彎／測速欄位、排入的 `json:guidance_current`／`json:speed` 等資料是否 `present=true`、Carrot 是否回報相符且持續更新的內容。只有 10019/40、12205、13022 或通知文字可見，不構成串接成功證據。

通知授權頁支援 App 專用頁 → 系統通知存取頁 → 系統設定的備援入口。「停止取樣」只停止診斷記錄，不是停止原導航傳送的開關。

## 回復

版本碼為 26110727。修改包內的 `Navipilot-9.3.1-wide.11-auto-restore-build27.apk` 是原 wide.11 高德車機版＋神盾，只提高版本碼以便覆蓋回復；原程式逐檔相同。它不包含 wide.14 台灣測速面板。不要以解除安裝的方式處理版本回退，以免遺失設定。

## 驗證與限制

- 通知快照的 8 個 JVM 回歸案例通過，覆蓋已存在但未更新的通知、重新取樣、區分一般版／車機版、空通知、讀取失敗、服務斷線與重綁。使用 Android 框架替身，並非實機測試。
- APK 編譯、簽章、16 KB 對齊、3688 個 smali 類別重組比對、689 個 App 方法／欄位參照通過。
- 保護原解析器、原傳送及拖曳／雙投屏生命週期的離線比對通過。
- 未在使用者 Android 車機執行，也沒有確認高德 17.02.2.2014 會輸出完整資料。不能宣稱一般版導航／測速已實車接通，亦未驗證 NOO 或自動減速。
- 未修正 C4 的 `state_send_timeout`；本版無 C4 端程式修改。
- 此版本沒有納入 wide.14 已知錯配的台灣測速控制來源。

## 重建

需要 Java 17、Python 3.9+、ripgrep、Apktool 3.0.3（`tools/apktool.jar`）、ECJ 3.39（`tools/ecj.jar`）、Android 35 SDK（`tools/platform/android-35/android.jar`）及 Build Tools 36.0.0。工具不包含於本修改包；程式碼、精確基底 APK、編譯 helper 與測試簽章已包含。設定 `ANDROID_BUILD_TOOLS` 後在新的解壓目錄執行：

```bash
bash phone15-src/test_notifications.sh
bash phone15-src/rebuild.sh
```

測試簽章 alias 為 `navipilot-wide-test`，密碼 `android`，沿用先前個人測試版本。JVM 測試替身、編譯 stubs 均未放入 APK。
