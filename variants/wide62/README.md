# Carrot Bridge 道路速限只採用 OSM

以 wide.60 為基礎。打包前先由使用者確認。對已反組譯的主 DEX 目錄套用
`patch.py`，沿用現有的 Navi v2 連線與送出診斷。此版本不套用 wide.61 的高德速限顯示候選改動。

- 道路速限採用手機既有離線 OSM 配對所確認的道路及方向，直接讀取圖資的
  forward/backward 限速欄位。既有 GPS 過期、模擬定位、路段重疊等檢查由配對器負責。
- 在三種來源共用的送出路徑先移除原有 road_limit_kph 和高德預調速標記。
  OSM 有符合現行 C4 協議的數值時才填入 road_limit_kph。未確認或缺值時撤銷，
  既有測速提醒、區間測速欄位與轉彎引導沿用原流程。
- C4 現行道路限速接收規則只接受 10 的倍數，其他數值不四捨五入。
- 車端自行取得的原廠速限或原生 Mapbox 資料由車端管理。

## App 地圖速限牌

先套用 `patch.py`，再執行 `patch_badge.py <主 DEX smali> <Google DEX smali> <Android 工具目錄>`。
第二步只編譯速限牌並修改兩個反組譯目錄。正式打包時需要重組主 DEX 與 Google DEX。

- 高德一般版與車機版使用投屏地圖容器。Google 導航 NOO 使用內建導航畫面的地圖容器。
- 預設在地圖左上。長按後可拖曳，三個模式分別儲存相對位置。點一下速限牌可恢復當前模式的預設位置。
- 速限牌與診斷共用 OSM 讀值，查不到時顯示 `—`。

## wide.63 定位與速限牌

取得 Android 精確定位權限後，App 進入前景時自動啟動定位服務。
設定列表的「顯示 OSM 速限牌」預設開啟，只控制地圖上的速限牌。
速限圓牌從 52 dp 放大到 66 dp，保留各地圖的位置記憶。
沿用臺灣 OSM 離線圖資，圖資不含測速點。

建置參數為 wide.60 unsigned APK、Android 工具目錄、輸出 unsigned APK 路徑、
以及含 `work/assets/tw_hcop/` 的原始 OSM 資料封存檔。

調整分隔線時保留已建立的地圖與神盾投屏解析度，按原比例縮放現有畫面。
切換來源及投屏失去 Surface 後仍會走既有建立流程。

「傳送 OSM 道路速限至 C4」預設關閉。開啟後只傳已確認的 OSM
道路速限。關閉時，Navi v2 仍可發送速限撤銷及其他既有導航資料。
離線圖磚僅保留 OSM 道路資料，移除舊封存檔的測速點和官方速限修正層。
