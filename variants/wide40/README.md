# wide.40 方向補足與高架／平面測速提醒

## 修改行為

- 提醒專用 WideAlertMotion 以多筆GPS位置補足短暫缺失的方向／速度；至少3筆、1.5秒，位移超過20公尺或兩端精度總和。保留最多8秒軌跡，缺更新超過3秒重新開始；停車、轉向不一致、明顯跳點與不佳定位不推算。
- 不改寫原始GPS或控制方向。WideHcop 原本對不可靠方向仍撤銷控制，只額外讓可用位置進入圖資載入／提醒流程。
- 提醒端不因高架和平面重疊而一律拒絕。對前方同向道路分別找候選，在候選穩定後優先顯示較近測速點；可能提醒到另一層道路，符合使用者接受的取捨。
- 仍需方向與前方道路條件，反向及已通過的點不提醒。沒有回到周圍半徑內有點就播報。仍沿用既有487個配對點，不代表1856個固定點已全部啟用。
- 點位標籤依相機所配對OSM道路的 layer/bridge/tunnel資料，而非車輛高度。layer>0或bridge=yes/viaduct標高架；0|no|no標平面；隧道、地下或缺資料保留「道路層級未標明」。此為圖資分類，預設或過時標籤可能錯誤，非現場測量。
- 1公里內播報「前方平面道路測速」／「前方高架道路測速」。新增兩段預錄台灣中文女聲（zh-TW-HsiaoChenNeural）；未分類點仍播放原A「前方測速照相」，不宣稱新錄音與舊A音色完全一致。示範按鈕仍播放原A。
- wide.39的高德預調速綁定、控制合併、固定關閉按鈕保留；GPS控制資料未放寬。

## 驗證

30項純Java離線檢查涵蓋：缺方向／速度推算、停車漂移、過期／模擬／跳點／轉彎、不佳精度、同座標高架平面候選、語音檔路由、反向／通過點排除，以及控制原資料不被改寫。另檢查最終APK、相同簽章、對齊與控制核心類別差異。尚未經車機實機、實路GPS或C4實車驗證。

## 使用與重建

[APK下載](https://github.com/FANHAOHSIANG/copilot-Tw/releases/tag/wide.40)。同簽章覆蓋更新。開啟定位及測速語音即可；停車時不靠漂移判斷方向。

重建使用已公開wide.39或本版APK作基底，雜湊須符合verification.json；設定COPILOT_BASE_APK、COPILOT_APKTOOL、COPILOT_BUILD_TOOLS與本機簽章環境變數後執行rebuild.py。私鑰不包含於公開材料。程式預設複製smali，修改Java後須先重新編譯ECJ/D8成對應smali。

Java測試：編譯src/*.java及tests/*.java到獨立classes資料夾，執行com.navipilot.obf.AlertChecks。測試含相依型別原始碼，不包入APK替換控制核心。
