# wide.43：不導航時的離線道路前方搜尋

版本 `9.3.1-wide.43-offline-forward`，versionCode `26110755`。沿用 wide.42 套件名稱與簽章，可覆蓋安裝，不必先移除設定。最低 Android 12（API 31）沿用原版。

新加入的 WideForwardRoads 從目前軌跡候選道路沿 OSM 共用節點向前搜尋最多 2,000 公尺。遵守單行道方向，優先同名道路及較小轉角，每個路口最多保留 3 個分支，全域最多 256 個狀態、深度 64。道路資料沒有可靠的道路寬度／等級欄位，因此不能宣稱依「大條路」精準判斷，也不能保證猜中駕駛在下一個路口的選擇。候選分支在診斷原因中標記。沒有設定目的地時，不預測先離開原道路、經側路再接回原道路的路徑，避免誤猜跨越分隔島進入另一側車道。

測速點距離改用候選道路沿線距離；原本約 1 公里語音、500 公尺強化閃爍、高架／平面文字和語音仍沿用。固定點、區間測速既有 UI 未重新設計。保留 wide.42 的 GPS 距離／方向備援、停車與過期資料處理；此版不修改 WideBridge 或 C4 控制來源仲裁。

載入視窗由 3×3 擴大為 5×5 個 0.02 度圖磚，避免位於圖磚邊界時看不到 2 公里內道路；圖磚快取上限由 12 調至 32。仍由原有背景工作執行。增加的記憶體與延遲需實機量測。

反向／通過處理採保守規則：測速點落在目前航向後方，或相機道路方向與目前航向相差超過 90 度時，不觸發道路提醒。迴轉型彎道的相機因此可能要等實際轉彎後才提醒，避免沒有導航目的地時猜測繞行而增加反向誤報。轉入其他道路後重新配對；不是永久鎖定先前預測分支。

## 驗證與限制

- Java 合成案例涵蓋既有 63 項，以及 14 項前方搜尋測試。Google 選用模組另有 8 項生命週期測試。
- 17 個情境稽核，另以 APK 內實際道路圖資產生 539 組方向回放；結果在 verification 目錄。這是道路中心線合成軌跡，不能當作 539 次實車成功。
- APK 簽章與 wide.42 相同，驗章與 16 KiB zipalign 檢查通過。尚未在使用者裝置測試安裝、音訊、效能或 C4 接收。
- 既有圖資與 1,856 筆固定測速點資料保持原樣。道路配對只覆蓋部分點，其餘依 wide.42 備援規則處理。
- 科技執法清冊位於 `data/enforcement`，來源紀錄不等於去重後的完整全台有效點位；此 APK 尚未把新增科技執法清冊接進獨立提醒 UI／語音，不將非測速執法冒充速限。
- Google 個人金鑰模組與 HCOP 接法說明位於 `variants/google-byok`；此 APK 未包含 Google 導航介面。

## 還原可安裝 APK

安裝 Python `bsdiff4`，執行 `python3 release/wide43/publish.py`。它在需要時先還原 wide.42，再套用已驗證的二進位差異，檢查 SHA-256。無需也不提供簽章私鑰。

重新建置則以 wide.42 APK 解包，覆蓋本目錄 smali（不包含 tests），更新 apktool.yml 的版本號，使用 Apktool 3.0.3 重包、zipalign，再用自己的受控簽章環境簽署。不同簽章無法直接覆蓋原安裝。
