# CP 搭子：wide.16 HCOP 台灣道路速限測試版

基底為你目前的 Navipilot 9.3.1-wide.14-tw-bridge 台灣測速版。此版維持高德車機版投屏與原有導航流程；不是 wide.15 的高德一般手機版分支。

## 安裝與使用

1. 停止投屏並關閉 CP 搭子，覆蓋安裝 `Navipilot-9.3.1-wide.16-hcop-tw-test.apk`。同套件、同簽章，versionCode 26110728，高於 wide.14 與 wide.15；不需先解除安裝。
2. 連接原來的 C4，啟動高德車機版，保留原 Navi v2 導航傳送設定。
3. 右上按「GPS」，允許精確定位。先查看「道路速限」的路名、來源及下方測速點是否符合現場。資料須有有效行進方向才會確認，停車時顯示 — 是設計行為。
4. 要測試送往 Carrot，進入「設定」→「啟用 HCOP 台灣道路速限＋測速（測試）」。App 每次重新啟動先使用高德，台灣資料只預覽。切回高德即可立即恢復原資料合併方式；網路中的撤銷仍依既有通道處理。
5. 「開始測試紀錄」會記錄 GPS、路段、來源、拒收原因、實際封包及接收回報；測試後選「停止並匯出測試紀錄 ZIP」。紀錄留在裝置上，只有按分享才匯出。

## 實際移植與補強

- HCOP 參考固定於 `henryopen/openpilot` 的 `full` 提交 `2decc11c5d8cebbdb87c0751ef52b96a494506c0`。
- OSM 離線圖資：Geofabrik Taiwan 2026-11-08，554,135 條 way，切成 1,159,186 段路口間道路、5,927 個壓縮圖磚。按位置載入相鄰圖磚，快取最多 12 塊，不需 Mapbox 或圖資 API 金鑰。
- HCOP 修正表：保留來源快照 12,954 筆，其中 12,152 條有方向的 TDX 速限路段用於比對，TDX 快照日期為 2026-10-18。這些是資料列數，不代表覆蓋全台所有道路，也不代表標誌於該日重新現勘。
- 警政署：沿用台灣版 2026-11-09 下載的 1,856 筆固定點；482 筆通過離線道路關聯初篩（舊版 226 筆）。仍須逐次通過 GPS、方向、道路歧義與連續定位檢查，不能當成 482 點均已實車驗證。
- 優先順序：同路段同方向測速點的局部速限修正 → 同道路名稱／編號、同方向的 TDX 路段 → OSM 的方向性 maxspeed。兩筆同優先來源互相衝突時，該筆道路速限不採用。
- 收緊 HCOP 的廣域修正：原表的圓形／整區方框保留在來源包供查閱，不直接拿來改整條道路。警政署局部修正限制在已關聯的同一個路口間路段、同方向，沿路距離 ±200 m。
- 道路配對納入沒有速限值的鄰近道路，避免只在「有速限的道路」中挑最近者。平行道路、不同層級道路或路口無法區分時拒收；這是保守排除，不是已能辨認所有高架上下層。
- 定位精度 ≤15 m；來源時間 ≤3 秒；有效行進方向；至少 3 次定位、跨度 ≥1.5 秒且位移 ≥5 m。定位跳點、過期、模擬定位、反向或來源切換均重置確認。
- 圖資解析與道路配對在背景工作執行，位置只保留最新待處理值，不累積舊定位佇列。載入失敗即不提供新速限。
- 資料包的使用期限至 2027-02-15。裝置日期早於 2026-10-31 或到 2027-02-16 起不送台灣資料，需更新資料包；這是版本的新鮮度上限，不是現場速限有效性保證。

## 畫面與既有功能

上方獨立顯示「道路速限、OSM／TDX／NPA、路名、確認狀態」，下方顯示已確認同路段的固定測速與沿道路距離。無可信資料顯示 —，未配對的附近點不再用大字呈現為正在行駛道路的速限。

新北區間及寬鬆固定點候選仍保留在詳細診斷；區間配對尚未完成，本測試版不在主要面板呈現估計區間計時，也不送出區間控制。示範畫面仍可操作，示範會切回高德來源，示範數值不傳送。

GPS 前景服務、投屏、拖曳版面、車況診斷、手動按鍵、UDP 與高德轉彎／路線均沿用 wide.14。這不是 wide.15 一般手機版高德的合併版，也沒有宣稱新增手機直式自動排版。

## 傳給 C4 的內容

沿用原本協商的 Navi v2 WebSocket（通常 7714），只在現有 `speed` 流合併欄位：

- 道路速限：`road_limit_kph`。
- 固定測速：`sdi.type=1`、`sdi.speed_limit_kph`、`sdi.distance_m`。
- 道路速限和相機速限分開；遠處的測速點不直接充當目前道路速限。
- 台灣模式撤銷高德的道路速限、主／副測速及區間欄位，再放入有效台灣結果。缺資料時不暗中回退高德；手動切回高德才恢復原流。
- 高德目前車速等其他 speed 資料只有來源時間 ≤2 秒才保留，且封包時間不晚於其中最舊的來源。新 GPS 不替過期高德資料續命。
- GPS 逾期時，本 App 的有效性檢查會撤銷資料；送到車端的時間仍受原排程、連線和接收端過期機制影響，不能宣稱斷線瞬間已清掉 C4。
- 支援「只有道路速限」的接收確認，核對主機、session、sequence、道路值及測速值。佇列接受、C4 接收和車輛實際減速是不同階段。

本包沒有改動 C4，也沒有更改你 Carrot 的速限調速開關、偏移量或縱向控制設定。是否調速仍由 C4 既有設定、導航有效性與規劃器決定。

## 已驗證與限制

- 44 項來源優先序、方向、道路歧義、GPS 時效、連續確認及封包合併斷言通過。
- 12 項橋接／接收回報斷言通過，包括只有道路速限、錯目標、錯序號、錯值與過期回報。
- 使用實際離線圖資上的合成位置，檢查背景載入、圖磚快取、資料配對及撤銷；結果在 `work/build/runtime-map-tests.json`。合成位置不等於行車紀錄，比例不能當成實車成功率。
- 已以使用者 GitHub `test/carrot-wip-upstream-20261104` 提交 `97830a1ffe5b079c1326da0b97ed065cbb4ea125` 的接收程式測試：協商、封包正規化、道路／相機各自套用、撤銷有效性、轉彎保留與偏航拒收。此 SHA 是 GitHub 查得版本，未證實是 C4 目前安裝版本。
- APK 已檢查簽章、16 KB 對齊、實際 DEX 方法／欄位引用及解包重組一致性。`MG/XG/Ae/IG/Od/Z3/h4` 等原核心類別相對 wide.14 保持原樣。
- 尚未在 Android 車機或實車執行；尚未證實該車機的 GPS 精度、背景運作、來源覆蓋或 Carrot 實際減速表現。
- 固定點不跨路口猜測路線；平行／重疊道路與未知方向會留下空白。這版不是所有路段、所有測速點都可用的完整導航引擎。

## 回復

最快方式：設定切回高德即可停用台灣欄位替換。

若需回到原台灣版，覆蓋安裝 `Navipilot-wide.14-restore-build28.apk`。它是原 wide.14，只提高 versionCode 至 26110728 以便覆蓋；原版已有的限制也會恢復。不要先解除安裝，以免遺失 App 設定。

## 修改包與重建

這是原 APK 的可重建 Java／smali 補丁，沒有原作者完整 Android 專案。根目錄包含精確基底 APK、沿用的個人測試簽章、程式碼、圖資、來源快照與檢查結果。此簽章備份僅供本人保管。

一般重建不必重新下載 OSM，直接使用已附的圖磚。需要 Python 3、Java 17、ripgrep；執行：

```sh
bash work/src/setup_tools.sh
bash work/src/rebuild.sh
```

工具為 Apktool 3.0.3、ECJ 3.39.0、Android API 35、Build Tools 36.0.0，依固定版本下載及 SHA256 檢查。JVM 測試使用 org.json 20240303，測試替身與編譯 stubs 不放入 APK。

圖資重建：下載 `https://download.geofabrik.de/asia/taiwan-261108.osm.pbf` 至 `work/data/`，MD5 為 `f7082133498609d8cd55b742c85f8a1d`；安裝 osmium、shapely 至 `work/python`，依序執行 `work/src/extract_osm.py` 與 `work/src/build_map.py`。輸入使用固定快照，更新資料日期時亦須更新程式中的有效期及重新驗證。OSM 原始 PBF 和中間資料不重複包入修改包。
