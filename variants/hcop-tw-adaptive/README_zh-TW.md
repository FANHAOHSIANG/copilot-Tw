# CoPilot Tw wide.17：HCOP 台灣測速＋自動橫直排版

APK：`CoPilot-Tw-9.3.1-wide.17-hcop-tw-adaptive.apk`，versionCode `26110729`。Android 12 以上；與原 wide.16 同套件、同簽章，可覆蓋更新並保留設定。App 顯示名稱統一為 **CoPilot Tw**。

## 為什麼原來看不到自製台灣測速？

原 HCOP wide.16 的 WideLayout 只在橫向且寬度 ≥600 dp 時啟用客製分割畫面，直向或較窄視窗會走舊版畫面分支。台灣面板程式與圖資確實存在於 APK，並未漏包。Auto／Phone Adaptive 的右側則是神盾投屏，本來就沒有包含自製台灣面板。

此為由 APK 解包及程式確認的顯示條件；沒有取得當時裝置截圖與視窗尺寸，不能斷定使用者那次畫面的唯一成因。

## 這版合併內容

- 以 HCOP wide.16 APK 為基底，合併 Adaptive 的橫直向排版、系統邊界處理、拖曳比例及橫直獨立保存。
- 橫向左導航、右台灣測速；直向上導航、下台灣測速。小視窗預設收合快捷鍵，可按「快捷／收合」切換。
- 右／下方是自製台灣原生面板，包含道路速限、來源、路名與固定測速資訊，不需要神盾 App 或神盾投屏。
- 台灣面板工具列採「GPS／快捷／更多」。更多包含版面設定、台灣測速設定與診斷、固定／區間示範與回到實況。
- 短視窗內面板可捲動，避免 GPS、速限或測速圖卡被裁掉。示範只顯示模擬數字，沿用原本切回高德來源的行為。
- 高德車機版仍為導航投屏來源，需原有 Shizuku／投屏授權。沒有改成高德一般版。
- HCOP 道路配對、GPS 判定、速限合併、接收確認、資料來源與 Navi v2／UDP 核心程式保持原樣；沒有擴大可傳送的測速候選。

## 安裝與使用

1. 停車時停止投屏、關閉舊 App，直接安裝上述 APK，不需先解除安裝。
2. 開啟 **CoPilot Tw**；確認 App 資訊版本為 `9.3.1-wide.17-hcop-tw-adaptive`。
3. 連接原 C4，啟動高德車機版投屏。台灣面板是原生畫面，不需另外開神盾。
4. 在台灣面板按 GPS，允許精確定位。沒有可信資料時顯示 —，不會填入假速限；實況需要有效方向及持續定位。可在「更多 → 示範固定測速」先確認圖卡，再選「回到實況」。
5. 「更多 → 台灣測速設定與診斷」保留資料來源切換與測試紀錄。預設高德來源、台灣只預覽；若要傳送仍須手動啟用 HCOP 台灣測試來源。這和面板是否顯示是兩件不同的事。
6. 旋轉或改變視窗大小，確認導航與台灣面板重新排列；拖曳後再返回原方向，比例應獨立保留。原車機若鎖定系統方向，App 依可用視窗尺寸排版，不強制旋轉系統。

## 程式與重建

公開程式碼不包含私人簽署金鑰；既有 APK 可直接安裝。

公開修改包包含精確 HCOP wide.16 基底 APK、這次的 UI Java／smali 修改腳本、編譯所需舊版來源及測試／檢查結果。不是原作者完整 Android 專案。

在乾淨解壓目錄準備 Java 17、Python 3、ripgrep，執行 `bash work/src/setup_tools.sh` 取得固定版工具。設定 `COPILOT_SIGNING_KEY`、`COPILOT_STORE_PASSWORD`、`COPILOT_KEY_PASSWORD`（必要時 `COPILOT_KEY_ALIAS`）後，執行：

```sh
bash adaptive17-src/rebuild.sh
bash adaptive17-src/test.sh
```

`adaptive17-build/` 附的 JSON／文字報告為此次建置結果。不要把簽署金鑰或個人定位紀錄提交到公開儲存庫。
