# 科技執法判定核心

本目錄提供離線科技執法的**畫面與語音提醒判定**，由 `variants/wide46` 的 Android runtime 接到既有 GPS、道路配對與介面。核心不讀取目的地，不呼叫網路 API，不修改原有台灣測速、Google、AMap 或 C4 傳輸，也沒有速限、目標速度或自動減速輸出。

## 資料與覆蓋限制

使用 `data/enforcement/tw_enforcement.json` 的 schema 1，來源為官方公告整理快照。此次驗證的資料源自提交 `7e89b4f4dcdaef96c2a857b8b77e6f6e3a413d36`，快照日期 2026-11-12，JSON SHA-256：

```text
b9c1f8d5ffe16494f5a4305f3b1e3e9639aa6e5f94a68d703c81f686410f31e3
```

快照共有 **2,148 筆公告，1,152 筆有可用座標，996 筆待定位**。待定位公告仍保留在原始清冊，但核心不猜座標、不把行政區中心或地址搜尋結果當作設備位置。

1,152 筆定位公告中，786 筆有非速度的已知取締類別；其中 307 筆另有明確 `travelBearing` 或明寫「南北雙向／東西雙向」的行向資料。只有「雙向」、相機位於「北側」、轉彎描述或空白方向，不能推出哪個接近方向適用。純測速、區間參考點與取締項目不明的公告，保留為參考，提醒聲音繼續交由既有測速功能負責。

原清冊有 43 組同地址的定位公告、45 筆額外同地址記錄；地址相同不代表同一設備。本核心只把同縣市、行政區、地址且相距不超過 12 m 的記錄合成一個顯示候選，保留適用記錄的 ID。各記錄仍分別判定方向與條件，反向或不確定的取締項目不會混進已確認提醒。同地址而座標明顯不同的記錄仍分開顯示。

## 分層提醒

| `Level` | 意義 | 主動語音 |
| --- | --- | --- |
| `AHEAD` | 目前道路已確認，公告可對應同名連通道路、分層及明確行向，條件沒有待確認事項 | 仍須通過連續接近與距離門檻 |
| `DIRECTION_UNKNOWN` | 公告在同路前方，但適用行向無法確認 | 通過接近門檻後，播放明說「取締方向待確認」的公告提醒 |
| `CONDITIONAL` | 同路前方，但公告另有未結構化的時段、假日或適用車種條件 | 不播放 |
| `NEARBY` | 鄰近公告，尚未證明是本車同路前方 | 不播放 |
| `REFERENCE` | 純速度、區間參考點、項目不明、未啟用、歷史快照或資料過期 | 不播放 |

`AHEAD` 表示道路與公告的適用條件符合本版提醒門檻，並非設備當下運作狀態的即時確認。

`DIRECTION_UNKNOWN` 的限定語音只提醒同路前方存在公告，維持方向未確認的原始狀態，措辭固定以「**前方有科技執法公告，取締方向待確認，請留意…**」開頭。它同樣要求唯一同路連通、層級無衝突、日期與車種／時段條件沒有待確認事項、已知非速度取締種類及連續接近；不宣稱本車這一向必然受取締，也不產生車控資料。`NEARBY`、`CONDITIONAL`、`REFERENCE` 一律不播放聲音。

所有鄰近距離在 `alongRoad=false` 時都是**直線距離**。只有完成道路配對的項目才標示沿路距離。UI 必須使用核心給的 `level`、`alongRoad` 和 `speechText`，不能根據附近圓形或自行比較距離決定「前方」及語音。

### 不需目的地的道路判定

核心接收既有 `WideHcopRoad.Data` 道路視窗和已確認的目前道路 `Decision`。它沿目前行向查找最多 2 km 的路徑，只延伸到**同名、同分層、節點連通且只有一個合理延續方向**的下一段路。延續夾角上限 35 度，最多 48 段；遇到同名分岔、轉入別條路、道路中斷或資料不足就停止延伸，不猜使用者將選哪條路。

公告還必須符合道路名稱，距道路中心線不超過 25 m。`AHEAD` 另要求公告行向和該處道路切線相差不超過 35 度；方向欠缺的公告只能保留 `DIRECTION_UNKNOWN`。不能用「一個點正好在車頭前方」取代道路證明。

目前位置附近有無法區分的高架／平面或平行道路時，不產生 `AHEAD`。公告座標處也會檢查其他道路層級；明寫高架、橋下、平面、便道、地下道等位置只允許相容層級。GPS 的二維座標不會被當作本車樓層證明。

如果公告座標明顯更貼近另一條不連接的平行道路（至少比所選道路近 5 m），即使那條路名稱不同，也降為 `NEARBY`。這可避免把平行便道公告誤說成本車主路的前方公告。上述分層與平行路排除，同樣適用於方向待確認的限定語音。

### 時間、車種與有效期

公告啟用日期未到時不產生有效提醒。包含時段、例假日、上課期間等自由文字，或限制車種的記錄，先標為 `CONDITIONAL`；本版不把不完整的文字解析成自行發明的活動時段，也不假設本車是大貨車、機車或其他受限車種。這次快照的有座標記錄沒有可直接判讀的完整時段表，因此沒有假日行事曆或計時啟閉功能。

來源明列「歷史快照」的公告僅供參考。總清冊快照超過 180 天、日期無法解析或裝置日期早於快照時停止新科技執法語音。這是本版的保守資料有效期政策，不代表設備依法在 180 天後失效。既有道路資料另有自己的有效期；`Data.expired` 時不進行前方配對。

## GPS、通過與語音生命週期

定位有效期為 **3,000 ms**，直接來自 GPS 的單調時間。重畫畫面、重複送入相同 GPS 時刻、或 raw 定位稍後取得道路資訊，都不能延長有效期。模擬定位、時間倒退、明顯跳點或過期定位會撤回提醒；鄰近顯示要求精度不超過 30 m，前方判定要求不超過 15 m。

兩種語音都需本車有效行進方向、速度至少 2 m/s、同一候選至少 3 次不同時刻的移動定位、歷時至少 1.5 秒，並實際接近至少 `max(8 m, 1.5 × 定位精度)`。語音距離為 `速度 × 12 秒`，下限 120 m、上限 400 m。輸出內容只提醒紅燈、行人、標線、轉彎、停車等類別，不念新速限或要求自動減速。方向待確認時使用前述公告措辭，不能共用確定行向提醒的句子。

語音提議至少間隔 8 秒；只有 Android TTS 接受後回覆 `spoken()` 才記錄為已播。本次選中的項目由 `Frame.speechAlertId` 指定，可能不是 `primary`。目前最近一個項目已經播過時，另一個可用候選可成為下一次聲音目標，不能把最近項目當作每次聲音的擁有者。

同一接近過程只播一次；同地址且相距不超過 80 m 的已播候選也會共用聲音去重。通過後撤回，離開超過 600 m 且至少經過 120 秒才重新允許同處提醒。畫面合併與語音去重是提醒層的行為，不宣稱這些公告是同一台設備。既有測速聲音的優先播放及 Android 音訊生命週期由 runtime 負責。

## 接線介面

```java
WideEnforcementEngine engine = new WideEnforcementEngine(catalogJson);

WideEnforcementEngine.Frame frame = engine.update(
    fix, roadWindow, currentRoadDecision, nowElapsedMs, nowWallMs);

// 只在本次 TTS 確實接受後回覆；speechAlertId 是本次聲音的目標 ID。
engine.spoken(frame.speechKey, nowElapsedMs);

// UI 讀取不累積定位樣本、不重新發送聲音。
WideEnforcementEngine.Frame view = engine.snapshot(nowElapsedMs);
engine.clear();
```

`Frame` 和公開清單不可修改，包含 `primary`、最多 12 個 `nearby`、`speechAlertId`、`speechKey`、`speechText`、`status`、`fixElapsedMs`、`expiresElapsedMs`。`Alert` 包含 `id`、`location`、`categories`、`recordIds`、`level`、`reason`、`directionText`、`distanceMeters`、`alongRoad`、`expiresElapsedMs`。核心不直接播放聲音、讀檔、操作 Android 服務或輸出定位日誌。

## 驗證結果

`tests/EngineChecks.java` 目前有 **67 項判定與生命週期檢查**，涵蓋未知／反向行向、離線連通路徑、斷路、岔路、高架平面、平行道路、時間與車種條件、純速度記錄、未定位與未啟用資料、資料期限、重複 GPS 時間、raw→road 升級、通過撤回、語音去重、聲音擁有者及清單不可變性。新增檢查確認限定公告保持 `DIRECTION_UNKNOWN`、保留語音中的方向不確定文字，而且不放寬附近圓形、時間條件或不同名平行便道的排除。

`tests/CatalogRoadAudit.java` 使用這次官方資料及 APK 既有的 OSM 2026-11-08 道路幾何，對有座標公告做 **3,686 組**合成接近情境。它包含相鄰前一段同名道路，不因設備靠近短 OSM 路段端點就跳過測試。每組提供三次前進定位，並**假設目前道路已由 Trace 確認**。結果完整保存於 `tests/catalog-road-audit.json`：

這次測試中的其他縣市仍沒有達到科技執法語音門檻，詳見逐筆結果。此比例不包含原本就能提醒的台灣測速點，也不能用來宣稱全台科技執法已完整提醒。資料與道路門檻沒有為增加聲音而放寬；新增的聲音只針對已確認同路前方、適用方向尚待確認的公告，並把這個限制說出來。另補上的不同名平行便道排除，讓原先一筆 `AHEAD` 及兩筆方向未確認候選退回 `NEARBY`。

這是**資料與判定規則的合成可用性測試**，不是實際 GPS 配對成功率、設備仍存在的查核、Android 語音或實車驗證。道路資料缺漏、官方點位偏移、公告方向不明及嚴格分層檢查都會降低可提醒比例；不以放寬成單純距離圈來補足。

執行純 Java 測試：

```sh
python variants/enforcement-alert/tests/run_checks.py \
  --java /path/to/jdk/bin/java \
  --javac /path/to/jdk/bin/javac \
  --json-jar /path/to/json.jar \
  --catalog data/enforcement/tw_enforcement.json
```

如需重跑真實道路合成回放，再加 `--tiles /path/to/decoded/assets/tw_hcop --audit-output /path/to/report.json`。測試程式使用 Java 11 以上的檔案 API；App 核心可按專案既有 Java 8 / Android API 31+ 設定編譯。
