# wide.37 全台固定測速離線驗證

2026-11-11 完成包內 1856 個固定點的清單／配對檢查。487 個有配對資料的點，依其配對方向展開成 539 組合成定位回放。測試版本 APK SHA-256 見 apk-verification.json。

| 結果 | 點數 |
|---|---:|
| 未進入提醒配對 | 1369 |
| 已配對方向在本次回放通過 | 457 |
| 部分方向未觸發 | 3 |
| 可用回放路徑不足 | 19 |
| 同向回放未觸發 | 2 |
| 反向回放異常待查 | 6 |

這些分類互斥，共 1856 點。「通過」只表示本次合成 GPS 可以形成提醒目標，不代表已在車機發聲、實地相機資料已核實或 C4 已採用。487 個有配對資料的點中，另有 6 個原始方向欄為雙向、但配對清單只含一向，此旗標與上述分類重疊。

539 組方向案例中，首次形成 1 公里內目標的距離為 900–1000m 共 272 組、500–899m 共 102 組、20–499m 共 140 組，另 25 組沒有形成目標。這不是語音裝置實測。

## 方法與邊界

- 全部 1856 筆檢查 ID、座標範圍、速限欄位、方向、是否存在於 wide.37 配對集合，以及已配對 edge 是否存在。
- 使用原資料中的 482 點，加上 wide.37 額外 5 點，合計 487。測速配對並未擴充。
- Java 使用原 WideHcopRoad.Tracker，加上 wide.37 WideCameraTrace.update/display。每一個定位更新依實際 0.02 度網格讀取 3×3 tiles，包含附近其他道路、相機和官方速限線。不人工強制 confirmed。
- GPS 在道路中心，精度 9m，每秒一筆。速度取速限的 80%，限制在 5–20 m/s。從前方最多 1200m 起步，循唯一同名道路回溯建立路徑。分岔不猜路。距離採道路幾何。
- 未配對 1369 點的結論是「程式清單沒有這個點」，不是對其實體道路正確性或現場相機狀態的驗證。
- 某些映射道路很短或道路回溯遇到歧義，無法生成至少 3 筆定位。這類列為路徑不足，不能直接說實車必定漏報。
- 對僅執法一個配對方向的案例，將生成的同向路徑反序、方向反轉，再檢查是否仍選到原相機。對雙向執法不將合法另一方向算誤報。反向出現目標的 6 點列為異常，需再核對迴轉拓撲、道路選擇及合成路徑。不是已證明實車必定誤報。
- 沒有測真實 GPS 飄移、手機背景服務、定位權限、Android UI／音訊、C4 接收或實際減速。沒有核實全部相機目前是否存在／啟用。本次沒有建立新 APK。
- 範圍僅包內固定測速點，不含區間測速、高德獨立提醒或流動測速出沒點。

## 檔案

all-points.json 為逐點完整清單。all-status.tsv 是精簡 ID 對照。replay.tsv 是 539 組方向結果。anomalies.json 包含有配對但未通過的點。reverse-evidence.tsv 是反向測試出現目標時的合成座標、方向及選定道路。所有座標均由公開道路幾何生成，不是個人行車紀錄。

## 重跑

先將 wide.37 APK 的 assets 解到 assets 目錄，或設定 COPILOT_ASSETS 指向該目錄。使用 Python 3 與 JDK。

```bash
python3 prepare.py
mkdir -p classes
javac -encoding UTF-8 -source 8 -target 8 -d classes src/*.java FullCameraAudit.java
java -Xmx1200m -cp classes com.navipilot.obf.FullCameraAudit . 2> reverse-evidence.tsv
python3 report.py
```

prepare.py 會產生約 104MB 的中間 tiles，未包含於下載包。來源相機資料快照 2026-11-09，OSM 快照 2026-11-08。公開圖資 © OpenStreetMap contributors / ODbL 1.0。警政署測速點依政府資料開放授權條款第 1 版。
